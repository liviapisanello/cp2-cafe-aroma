# ☕ Café Aroma

## 📌 Descrição do projeto
O projeto **Café Aroma** foi desenvolvido como parte do Checkpoint 2 da disciplina de Front-End, com o objetivo de simular o desenvolvimento de um site institucional para uma cafeteria.

A aplicação apresenta uma interface visual que busca reproduzir um ambiente digital moderno e organizado. O site contém diferentes seções que representam elementos comuns de uma cafeteria real, como apresentação da marca, exibição de produtos, serviços, informações de contato, redes sociais entre outros.

Além do aspecto visual, o projeto também teve como foco a aplicação de boas práticas de desenvolvimento, incluindo a estruturação semântica com HTML, estilização com CSS e utilização de versionamento com Git e GitHub por meio de branches e Pull Requests.

Dessa forma, o projeto une conceitos de design e desenvolvimento.

---

## ⚙️ Funcionalidades

- 📌 Estrutura de página com header, banner e footer  
- 📝 Seções informativas sobre a cafeteria  
- 🧾 Exibição de produtos em formato de cards  
- 🖼️ Galeria de imagens  
- 📞 Área de contato com informações da empresa  
- 🎨 Estilização com CSS seguindo layout do Figma  
- 🔀 Uso de branches para desenvolvimento de funcionalidades
